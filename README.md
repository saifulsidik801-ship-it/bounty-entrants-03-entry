# Bounty Entrants 03 — Meme Sprint 3: AI Agent Goes Rogue (FREE)

This repository is my entry for the make.fun **bounty-entrants-03** competition,
which rewards the entrant whose launched bounties attract the most entrants.

The bounty this entry points to is **"Meme Sprint 3: AI Agent Goes Rogue"**,
a judged-image bounty I launched on make.fun. Entrants submit their funniest
image meme about an AI agent that has gone rogue, and the house counts every
entrant — entry is **FREE**, no fee to join.

- Entry fee: **$0 (free)**
- Prizes: **$5** split across the top 10 (1st $1.54, 2nd $1.08, 3rd $0.76)
- Judging: a judge model compares the pictures two at a time

`BOUNTY.json` names the bounty by its make.fun id, and `main.ts` copies that
manifest into the output directory so the competition can tally its entrants.
